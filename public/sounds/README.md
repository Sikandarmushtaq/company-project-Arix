# Notification Sounds

Place the following audio files in this directory:

| File | Purpose | Recommended Duration |
|------|---------|---------------------|
| `sms-notification.mp3` | Incoming SMS notification | 0.5-1 second |
| `call-ringtone.mp3` | Incoming call ringtone | 3-5 seconds (loops) |
| `voicemail-notification.mp3` | New voicemail notification | 0.5-1 second |

## Requirements

- Format: MP3 (for best browser compatibility)
- Sample rate: 44.1kHz or 48kHz
- Bit rate: 128kbps or higher
- Keep files small (<100KB) for fast loading

## Recommended Sources

- [Mixkit](https://mixkit.co/free-sound-effects/) - Free notification sounds
- [Zapsplat](https://www.zapsplat.com/) - Free with attribution
- [Freesound](https://freesound.org/) - Creative Commons licensed

## Fallback

If files are missing, notifications will still work but without sound.
The system silently handles missing audio files.
